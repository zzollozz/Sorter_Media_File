# Описание проекта
### Описание проекта: медиа‑сортировщик на Python

#### Назначение
Программа на Python 3.11 рекурсивно обходит директорию‑источник,
извлекает из медиафайлов дату создания из метаданных и сортирует их по папкам в целевой директории: по дате и типу (фото/видео).

#### Функциональные требования

**Алгоритм работы:**
1. Рекурсивный обход всех подпапок в директории А; подсчёт общего числа файлов.
2. Вывод прогресс-бара (`tqdm`) в терминал с именем текущего файла и счётчиком.
3. Системные файлы ОС (`Thumbs.db`, `.DS_Store`, `desktop.ini`) пропускаются молча без записи в лог.
4. Для каждого медиафайла:
    * Извлечение даты создания из метаданных.
    * Проверка наличия папки с этой датой в директории В; если нет — создание.
    * Определение типа файла (изображение/видео).
    * Проверка наличия подпапок «foto» для фото и «video» для видео внутри папки с датой; если нет — создание.
    * Копирование файла в соответствующую подпапку.
5. По завершении — итоговое сообщение в консоль и в лог-файл.
6. Логирование всех действий (успехи, ошибки, предупреждения) с помощью библиотеки `loguru`.

**Правила сортировки:**
* Корневая папка в В — дата создания файла (формат: `ДД-ММ_ГГГГ`).
* Внутри — две подпапки: «foto» и «video».
* Пример пути после сортировки: `В/15-05-2024/foto/IMG_001.jpg`.

#### Технические требования
* **ОС:** Debian 12.
* **Версия Python:** 3.11.
* **Права доступа:** только чтение для директории‑источника (А).
* **Логирование:** библиотека `loguru` (запись в файл `log_worker_media_sorter.log` и вывод в консоль только критических ошибок которые приводят к падению работы программы).
* **Конфигурация:** отдельный модуль настроек (`config.py` или `settings.py`) для путей, форматов дат, типов файлов.

#### Оптимизация хранения и конвертация

**Рекомендация по кодировке/формату:**
* Для **изображений:** конвертировать в **WebP**.
* Для **видео:** перекодировать в **H.265/HEVC**.

**Методы конвертации:**
* **Изображения:** библиотека `Pillow` (Python Imaging Library) для конвертации в WebP.
* **Видео:** использование утилиты `ffmpeg` через вызов подпроцесса (`subprocess`).
* При использовании библиотеки `subprocess` обратить на безопасный ввод аргументов и команд.

#### Зависимости

Все зависимости устанавливаются через `pip`. Основной файл — `requirements.txt`:

```txt
loguru==0.7.2
Pillow==10.0.1
exifread==3.0.0
python-dateutil==2.9.0
tqdm>=4.65.0
```

Для установки: `pip install -r requirements.txt`.

#### Архитектура проекта

```
media_sorter/
│
├── main.py                # Точка входа, парсинг аргументов командной строки
├── config.py              # Настройки (пути, форматы дат, расширения файлов)
├── file_processor.py      # Модуль для обработки файлов: чтение метаданных, определение типа
├── copier.py              # Модуль копирования и конвертации файлов
├── logger_setup.py        # Настройка логирования loguru
├── requirements.txt       # Список зависимостей
└── tests/                 # Папка с тестами
    ├── __init__.py
    ├── test_file_processor.py
    └── test_copier.py
```

#### Инструкция по запуску

**Шаг 1.** Клонируйте репозиторий или создайте папку проекта.
**Шаг 2.** Установите зависимости:
```bash
pip install -r requirements.txt
```
**Шаг 3.** Запустите программу:
```bash
python3 main.py <путь_к_директории_А> <путь_к_директории_В>
```
*Пример:*
```bash
python3 main.py /home/user/photos_source /home/user/sorted_media
```
**Шаг 4.** Проверьте логи в файле `media_sorter.log`.

#### Тестирование

Для тестирования используется стандартный модуль `unittest`:
* **Юнит‑тесты** для модулей `file_processor` и `copier` (проверка извлечения даты, определения типа, логики копирования).
* **Интеграционные тесты** в папке `tests/` (симуляция копирования файлов, проверка структуры папок).
* Запуск тестов:
```bash
python -m unittest discover -s tests
```

#### Поддерживаемые форматы файлов

**Изображения** (конвертируются в WebP; RAW-форматы — копируются как есть при неудаче конвертации):
`.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.tiff`, `.tif`, `.heic`, `.heif`, `.webp`,
`.cr2` (Canon RAW), `.nef` (Nikon RAW), `.arw` (Sony RAW), `.dng` (Adobe/Google RAW),
`.raf` (Fujifilm RAW), `.orf` (Olympus RAW), `.rw2` (Panasonic RAW)

**Видео** (перекодируются в H.265/HEVC; при недоступности ffmpeg — копируются как есть):
`.mp4`, `.mov`, `.avi`, `.mkv`, `.wmv`, `.flv`, `.m4v`, `.3gp`, `.mts`, `.m2ts`

**Системные файлы** (пропускаются без записи в лог):
`Thumbs.db`, `thumbs.db`, `.DS_Store`, `desktop.ini`

**Прочие расширения** — пропускаются с записью в лог (уровень DEBUG).

#### Краткий итог

Программа автоматизирует сортировку медиафайлов по дате и типу с возможностью оптимизации размера за счёт конвертации.
Ключевые особенности:
* рекурсивный обход директорий источника;
* сортировка по дате (из метаданных) и типу;
* прогресс-бар в терминале с именем текущего файла (`tqdm`);
* итоговый отчёт в консоль по завершении (обработано/пропущено/всего);
* поддержка RAW-форматов Canon, Nikon, Sony, Adobe и других;
* явное игнорирование системных файлов ОС без засорения лога;
* логирование через `loguru`;
* конвертация в WebP/H.265 для экономии места;
* модульная архитектура и тестируемость;
* простой запуск из командной строки.
